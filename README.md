# Purple Cross Employee Management Dashboard

A Vue 3 single page app for managing employee records: view, search, filter, sort,
create, edit, and delete employees, with CSV import/export on top.

## Stack

- Vue 3 + Vite + Vue Router + Pinia
- TanStack Vue Table (sorting, pagination)
- papaparse (CSV import/export), vue-sonner (toasts), @lucide/vue (icons)
- ESLint + Oxlint + Prettier

## Setup

```sh
npm install
npm run dev
```

```sh
npm run build   # production build
npm run lint    # oxlint + eslint
npm run format  # prettier
```
